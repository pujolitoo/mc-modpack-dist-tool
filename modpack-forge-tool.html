API de CurseForge

CurseForge bloquea las peticiones directas desde el navegador (CORS). Para buscar y resolver mods necesitas un proxy que añada los cabeceras CORS. Se guarda solo en este navegador.

Añadir mods

Se filtra por la versión de Minecraft y el loader del modpack.

Requiere API key (panel izquierdo) y un proxy con CORS.

Arrastra aquí archivos .jar o

Se calculan SHA-1 y SHA-256 y se lee el id, nombre y versión del mod desde el propio JAR. Al exportar puedes incluirlos en un ZIP junto al JSON, o asignarles una URL de descarga propia.

Modpack de CurseForge (.zip)

Arrastra el ZIP exportado desde la app de CurseForge o

Lee manifest.json: versión de Minecraft, loader y lista de mods (projectID / fileID). Si hay API key, se resuelven nombres, URLs y hashes. Los JAR dentro de overrides/mods se añaden como locales.

Solo overrides

Acepta un ZIP de CurseForge (usa su carpeta overrides) o un ZIP normal con carpetas como config, kubejs o resourcepacks. No toca los mods.
